# temperature-cereal-yield

This repository contains the Google Colab notebook `temperature_cereal_yield.ipynb`, the input datasets used in the analysis, and the main output files generated by the notebook.

The project is designed to run in Google Colab and includes a GitHub workflow that allows users to save their own changes and outputs back to GitHub. Since the original notebook is configured with repository-specific and user-specific settings, anyone who wants to run and modify the notebook must first update those settings to match their own GitHub account and Google Drive folder.

## Important note

This repository is public, so anyone can view and clone it. However, unless you have write access to the original repository, you cannot push changes directly to it.

If you want to run the notebook and save your own updates, the recommended workflow is to create your own fork of this repository and work from there.

## Repository contents

The repository includes:

- `temperature_cereal_yield.ipynb`
- `FAOSTAT_data_en_4-20-2026.csv`
- `monthly-temperature-anomalies.csv`
- `requirements.txt`

The notebook also generates and saves several outputs during execution, including processed data files, figures, regression results and map files.

## Python dependencies

This repository also includes a `requirements.txt` file listing the main Python packages used in the notebook.

The notebook is primarily designed to run in Google Colab, where the required packages are installed from within the notebook itself. The `requirements.txt` file is included as a reference for the project dependencies and may also be useful if you want to recreate the environment outside the default Colab setup.

## Recommended workflow for new users

1. Fork this repository to your own GitHub account.
2. Download or copy the following files into a folder in your own Google Drive:
   - `temperature_cereal_yield.ipynb`
   - `FAOSTAT_data_en_4-20-2026.csv`
   - `monthly-temperature-anomalies.csv`
3. Open `temperature_cereal_yield.ipynb` from Google Drive in Google Colab.
4. Update the GitHub and Google Drive settings at the top of the notebook.
5. Run the setup sections in the correct order.
6. Run the analysis sections of the notebook.
7. Save and push your changes to your own fork or to a branch in your fork.

## Before running the notebook

Before you run the notebook, you must update a few settings at the top of the file.

### 1. Update the GitHub settings

In the section `## GitHub setup`, replace the original values with your own:

```python
USER = "your_github_username"
EMAIL = "your_github_email"
REPO = "your_repository_name"
BRANCH = "main"
```

### 2. Update the Google Drive folder

In the section `## Link Google Drive and select files`, look at the second code block.

In that block, the first line is:

```python
DRIVE_FOLDER = "/content/drive/MyDrive/Colab Notebooks/Assignment/Notebook"
```

This path is specific to the original author’s Google Drive setup. To make the notebook work on your own account, you must change this folder path so that it points to the folder in your own Google Drive where you stored the notebook and the two CSV files.

For example:

```python
DRIVE_FOLDER = "/content/drive/MyDrive/your_folder_name"
```
